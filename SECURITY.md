# Security Policy

## Supported Versions

The following table lists the versions of AI Resume Analyzer currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |
| < 1.0   | No                 |

## Reporting a Vulnerability

If you discover a potential security vulnerability within AI Resume Analyzer, please report it responsibly.

### How to Report

- Email your findings directly to the repository maintainers or open a private security disclosure on GitHub.
- Do not create a public GitHub issue for security vulnerabilities.
- Include detailed steps to reproduce the vulnerability, proof of concept code, and impact analysis.

### Response Timeline

- Acknowledgment: Within 48 hours of report receipt.
- Assessment & Resolution: Security fixes will be developed and released in a patch release as soon as possible.
