# Contributing to AI Resume Analyzer

Thank you for considering contributing to the AI Resume Analyzer project. This document outlines the guidelines and best practices for contributing.

## How to Contribute

1. Fork the Repository: Create a personal copy of the repository on GitHub.
2. Clone Your Fork: Clone your repository locally to make changes.
3. Create a Feature Branch: Create a dedicated branch for your feature or bug fix.
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. Make Changes: Ensure code formatting standards are maintained.
5. Run Unit Tests: Verify all tests pass before submitting.
   ```bash
   python -m unittest test_resume_analyzer.py
   ```
6. Commit Changes: Write clear, descriptive commit messages.
7. Push and Open Pull Request: Push changes to your fork and submit a pull request against the `main` branch.

## Code Style & Formatting

- Follow PEP 8 guidelines for Python code.
- Write descriptive function and variable names.
- Keep functions modular and maintain single responsibility principles.
- Add unit tests for any new features or bug fixes.

## Reporting Issues

If you encounter a bug or have a feature request:
- Search existing issues to avoid duplicates.
- Open a new issue with a clear title and detailed description including steps to reproduce.
